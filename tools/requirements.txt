# The environment the level bakers are verified in. Python 3.11.15, the
# version of the python:3.11.15-slim image the `levels_check` job of
# gitlab/verify.yml runs on; install this file into it:
#
#     python -m pip install -r tools/requirements.txt
#     python tools/build_levels.py --check
#
# Pillow paints every background in assets/levels. It is pinned to the
# exact version so a baker run here and a baker run in CI paint the same
# picture. `--check` compares the decoded pixels rather than the bytes of
# the file, so a different PNG encoder or zlib does not fail the job on
# its own; the pin keeps the drawing itself from moving.
#
# Every picture generator runs in it: the sprite, outfit, quest-item, sign
# and icon generators through `python tools/build_sprites.py --check`, in
# the `sprites_check` job, the same way. They only need Pillow and the
# standard library. The audio (`tools/build_audio.py`) needs ffmpeg, not
# Python packages: see the version it declares.
Pillow==12.3.0
