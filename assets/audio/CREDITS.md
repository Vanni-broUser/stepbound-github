# Audio credits

Every file in this folder is baked by `tools/build_audio.py` from the sources
below. The music licences require the credits to be shown in the game itself:
they are on the main menu's CREDITI page (`musicCredits` in
`lib/game/audio/sound.dart`). Keep the two lists in sync.
